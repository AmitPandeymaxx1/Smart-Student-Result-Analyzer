**Smart Student Result Analyzer**
📌 Project Overview

Smart Student Result Analyzer is a desktop-based application developed using Python, Tkinter, Pandas, and Matplotlib. The system helps manage student records, calculate percentages, assign grades, determine pass/fail status, and generate analytical reports through interactive charts.

🚀**** Features****

✅ Add Student Records

✅ Delete Student Records

✅ Search Student by Name or Roll Number

✅ Automatic Percentage Calculation

✅ Automatic Grade Generation

✅ Pass/Fail Determination

✅ Dashboard Statistics

✅ CSV Import Functionality

✅ CSV Export Functionality

✅ Performance Comparison Chart

✅ Pass/Fail Pie Chart

✅ Grade Distribution Analysis

✅ Subject-Wise Average Analysis

✅ Histogram Visualization

✅ Top 10 Students Analysis

✅ Interactive GUI using Tkinter
